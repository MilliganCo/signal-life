# Signal Life

## Описание

Клеточная симуляция на `pygame` с интерактивной панелью параметров, метриками и несколькими типами частиц. Проект развивает идею автомата жизни в сторону сигнальных взаимодействий, зарядов и управляемого поведения системы.

## Возможности

- симуляция на сетке с несколькими типами состояний;
- влияние внешних сигналов;
- визуальная панель управления параметрами;
- просмотр метрик по ходу работы;
- пауза, изменение порогов и ручное рисование состояний.

## Стек

- Python
- pygame
- numpy

## Запуск

```bash
pip install pygame numpy
python main.py
```
